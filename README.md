# Chess-Assist
An assistantce tool for the game 'CHESS!' on Roblox. 

## Introduction
This is a simple Chess script that helps you in the Roblox game 'CHESS!' by highlighting the squares of the best move on the board. 
The script connects to a websocket provided by https://chess-api.com/ for the best moves, and sends the setup of the board using Forsyth-Edwards Notation everytime its your turn to move.
Keep in mind that their engine is sometimes busy, meaning it wont give out any moves until its available again.
